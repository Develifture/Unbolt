# Unbolt identity

The Release symbol is an unfastened U with a detached upper terminal. Its broad curve and open gap keep it recognizable in a Windows title bar. The approved identity uses mint on charcoal; ink is the preferred treatment on light backgrounds.

## Files

- `unbolt-symbol-*`: symbol-only vector masters. Use the white version on dark backgrounds; its strokes are optically thinned.
- `unbolt-horizontal-*`: fixed horizontal lockups. PNG is supplied for documentation.
- `unbolt-stacked-*`: vertical lockups for square layouts.
- `unbolt-wordmark-*`: original outlined wordmark, with no font dependency.
- `unbolt-symbol-small.svg`: grid-aligned drawing for 16–32 pixel use.
- `unbolt-app-icon.svg`: mint symbol on the charcoal Windows tile.
- `../unbolt.ico`: Windows icon with 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel images.
- `web/`: favicon, touch icons, maskable icon, and an example web manifest. Adjust the example root URLs when hosting under a subdirectory.
- `presentation.html`: self-contained preview with software-related applications. These are illustrative mockups.

## Palette

| Color | HEX | RGB | CMYK approximation |
|---|---|---|---|
| Mint | #5ED2C0 | 94, 210, 192 | 55, 0, 9, 18 |
| Charcoal | #171B23 | 23, 27, 35 | 34, 23, 0, 86 |
| White | #FFFFFF | 255, 255, 255 | 0, 0, 0, 0 |

Mint/charcoal contrast exceeds 9:1. Mint is an accent on light backgrounds; use ink for a small standalone mark on white. Print values are unproofed conversions; no Pantone match is specified or verified. Digital artwork uses sRGB.

## Size, spacing, and type

Keep clear space of at least one stem width (48/256 of the symbol canvas) beyond the artwork. Minimum symbol size is 16 pixels using the small drawing. Use the horizontal lockup at 160 pixels or wider and the standalone wordmark at 96 pixels or wider. At smaller sizes, use the symbol alone.

The wordmark uses original geometric path lettering, with no external font or font license requirement. Interface and supporting text use the Windows system font, Segoe UI. Never retype, stretch, rotate, outline, add effects to, close the gap in, or rearrange the supplied artwork.

## Handover

The mark was inspected at small sizes, in black, reversed, and alongside reference marks. SVG masters contain filled paths rather than live text or raster images. The artwork is supplied under the repository's MIT license. No trademark clearance or print proofing has been performed.
